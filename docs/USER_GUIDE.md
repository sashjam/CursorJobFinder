# JobDesk — инструкция пользователя

## 1. Установка и запуск

```bash
cd d:\_PHPStormProjects\Job
pip install -r requirements.txt
python main.py
```

Данные хранятся локально: `%LOCALAPPDATA%\JobDesk\jobdesk.db`.

---

## 2. Первый запуск (5 минут)

1. **Желаемая работа** — опишите вакансию (стек, роль, формат). Отметьте **города** или «Любая локация». Нажмите **Сохранить и искать**.
2. **Подписки** — добавьте сайты (Хабр RSS, HeadHunter, SuperJob и др.). У каждой подписки должен быть **включён** переключатель «вкл».
3. **Вакансии** — **Обновить с сайтов**. Смотрите строку статуса внизу окна.
4. **Настройки** — интервал опроса (минуты). При необходимости настройте Telegram (ниже).

---

## 3. Вкладки

| Вкладка | Зачем |
|---------|--------|
| **Вакансии** | Список найденных объявлений. 🆕 — новые, ✓ — просмотренные. |
| **Желаемая работа** | Текст идеальной вакансии + фильтр по городам. Сохраняется между запусками. |
| **Подписки** | Какие сайты опрашивать и с каким запросом. |
| **Настройки** | Интервал, Telegram, тесты. |
| **Источники** | Справочник сайтов и формата поля «Запрос». |
| **Справка** | Эта инструкция в приложении. |

### Вакансии — кнопки

- **Обновить с сайтов** — сходить на все включённые подписки.
- **Обновить список** — перечитать базу без интернета.
- **Только новые** — по умолчанию включено; снимите, если список пуст, а в статусе «уже в базе».
- **Прочитано** — убрать метку «новая» у одной вакансии.

### Желаемая работа

- **Искать по описанию** — подставляет запрос на сайтах из вашего текста.
- **Доп. фильтр по ключевым словам** — строже; если результатов 0, выключите.

## 4. Telegram

### Формат `.env`

Файл: **`d:\_PHPStormProjects\Job\.env`** (рядом с `main.py`). Образец: **`.env.example`**.

| Переменная | Что писать | Пример |
|------------|------------|--------|
| **BOT** | **Chat id** — число, куда слать сообщения (не @бот!) | `987654321` или `-1001234567890` |
| **BOT_TOKEN** | Токен от @BotFather | `7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw` |
| **BOT_NAME** | Подпись в тексте (любое имя) | `JobDesk` |

Правила:

- без кавычек: `BOT=123`, не `BOT="123"`;
- без `@` в **BOT** — только цифры (и минус для групп);
- после правки `.env` → **Настройки → Перечитать .env**;
- в Telegram откройте чат с **вашим** ботом и нажмите **/start** (иначе «chat not found» / «bot blocked»).

### Проверка

1. **Тест Telegram** — короткое сообщение.
2. **Тест: вакансия в Telegram** — пример как при новой вакансии.

Строка статуса внизу окна покажет ошибку API (неверный token, chat id, бот не запущен).

При новых вакансиях после «Обновить с сайтов» бот шлёт список автоматически.

## 5. HeadHunter

- Источник **HeadHunter (API → HTML fallback)**: при ошибке API используется HTML.
- Опционально в `.env`: `JOBDESK_HH_USER_AGENT=JobDesk/1.0 (ваш@email.com)`.

---

## 6. Если пустой список

1. Снимите **Только новые**.
2. Проверьте, что подписки **включены**.
3. Ослабьте фильтры на «Желаемая работа» (города, строгий фильтр).
4. Прочитайте **статус внизу окна** — там «с сайтов / подошло / новых».
